# 再現試験の記録（他PCでの導入テスト）

目的: **何も入っていないPCで、`docs/user_manual.md` だけを見て**、
ZIP取得 → Docker → APIキー → サーバー起動 → LabVIEW の VI 実行まで辿り着けるかを確かめる。

ルール:

- `README.md` 以外の資料、作った本人への質問、ネット検索は使わない。
  ただし、マニュアルに書いてある「AI への聞き方」は使ってよい（使ったら記録する）
- 止まったら、その場で時刻・画面・エラー文を残す。マニュアルはテストが終わってから直す
- APIキーの中身は、この記録にもスクリーンショットにも残さない

PCを変えて試すたびに、下の「記録」を1つ複製して埋める。
